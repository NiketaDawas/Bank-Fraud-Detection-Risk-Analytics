# Power BI Dashboard

This folder contains the Power BI dashboard screenshots and related dashboard resources for the Bank Fraud Detection & Risk Analytics project.

## Dashboard

The dashboard consists of 3 interactive pages designed to analyze:

- Fraud transaction overview
- Fraud patterns and transaction behavior
- Customer and transaction risk analysis

## Power BI File

The complete Power BI report is available as:

`bank_dashboard.pbix`

Due to the large file size, the PBIX file may be shared separately.
